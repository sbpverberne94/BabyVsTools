# Hoe groot is een baby?

Vergelijk per zwangerschapsweek de lengte van je baby met een herkenbaar stuk
gereedschap. Live op https://www.hoegrootiseenbaby.nl

Plain static site: `index.html` + `style.css` + `tools.json` + `images/`.
No build step. See [AGENTS.md](AGENTS.md) for how the data is structured and
how to edit it.
